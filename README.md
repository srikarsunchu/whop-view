# whop-view

`wv` is a human view layer for the [Whop CLI](https://whop.sh). It wraps `whop`,
asks it for JSON, and renders a designed table, card, confirmation, or error
when a person is looking. When a script or agent is looking it gets out of the way.

Status: spec only. See [VIEWS.md](./VIEWS.md).
