### payouts

Send money from a balance to a bank or wallet. · `wv agent payouts`

- `whop payouts cancel` · write, money, destructive
- `whop payouts create` · write, money · required: `--amount`, `--payout_method_id`
- `whop payouts create-method` · write, money · required: `--supported_payout_method_id`
- `whop payouts delete-method` · write, money
- `whop payouts get` · read
- `whop payouts list` · read
- `whop payouts methods` · read
- `whop payouts quotes` · read · required: `--amount`, `--payout_method_id`, `--idempotency-key`
- `whop payouts supported-methods` · read
- `whop payouts update-method` · write, money

### ledgers

The activity feed behind an account or user's balance. · `wv agent ledgers`

- `whop ledgers breakdown` · read · required: `--bucket`, `--direction`, `--currency`, `--from`, `--to`
- `whop ledgers list` · read
- `whop ledgers report` · read · required: `--report_type`

### transfers

Move funds between Whop accounts and users. · `wv agent transfers`

- `whop transfers create` · write, money · required: `--amount`, `--origin_id`, `--idempotency-key`
- `whop transfers get` · read
- `whop transfers list` · read
- `whop transfers recipients` · read · required: `--origin_id`

### swaps

Convert a balance between currencies. · `wv agent swaps`

- `whop swaps create` · write, money · required: `--account_id`, `--from_token`, `--to_token`
- `whop swaps get` · read
- `whop swaps quote` · read · required: `--amount`, `--from_token`, `--to_token`
- `whop swaps status` · read

### deposits

Add funds to a balance. · `wv agent deposits`

- `whop deposits create` · write, money · required: `--destination`

- `whop cards get` · read
- `whop cards get-transaction` · read
- `whop cards list` · read
- `whop cards transactions` · read
- `whop cards update` · write, money

- `whop verifications create` · write
- `whop verifications get` · read
